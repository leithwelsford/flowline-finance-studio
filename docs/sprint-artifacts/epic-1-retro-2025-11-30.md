   - react-refresh warnings in shadcn component exports
   - Impact: Non-blocking noise in lint output

## Key Insights

1. **Well-defined architecture documentation leads to smooth implementation**
   - The architecture doc essentially wrote the acceptance criteria
   - Clear technology decisions prevented mid-implementation pivots

2. **Container dev environments need explicit configuration**
   - Port forwarding should be configured in devcontainer.json
   - Don't assume "it works locally" means it works everywhere

3. **Test-first patterns established early create confidence**
   - 100 tests baseline provides safety net for future changes
   - Test count grew with each story (good pattern to maintain)

4. **shadcn/ui + Tailwind v3 is the stable combination**
   - Document this requirement to prevent future compatibility issues
